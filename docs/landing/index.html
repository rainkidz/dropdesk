Install (Android 7.0+)

  1. Tap Download APK above. Your browser will save tubenime-release.apk.
  2. Open the file. Android will ask you to allow installs from this source.
    • Stock Android: Settings → Apps → Special access → Install unknown apps → pick your browser → Allow.
    • Samsung One UI: Settings → Biometrics and security → Install unknown apps.
    • Xiaomi/MIUI: Settings → Privacy → Special permissions → Install unknown apps.
  3. Tap Install. Open TubeNime when done.
  4. (Optional) Join the community below for the latest updates.

FAQ

Why isn't this on the Play Store?

YouTube's Terms of Service forbid downloading their content, and Google Play has a strict IP policy. TubeNime is distributed as a sideload APK only — same model as NewPipe, Seal, etc.

Is this safe?

The official APK is signed with a fixed release certificate; the in-app SecurityGuard will mark any repackaged build as MODIFIED and disable premium. Verify the SHA-256 fingerprint of the downloaded APK against the value listed in the release notes.

How do I unlock 1080p?

Go to Settings → PREMIUM STATUS, tap WATCH AD → 30 MIN PRO, and watch the ad till the end. PRO stays active for 30 minutes, then you can watch again.
